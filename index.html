Research & Engineering

At IIT Jodhpur, I work with Dr. Palash Das on efficient AI inference. My work spans model optimization, HLS accelerator design, and end-to-end deployment on AMD/Xilinx platforms, with an emphasis on the trade-offs between accuracy, latency, power, and hardware resources.

Vision Transformers · FPGA · PyTorch

GateAttn-ViT

Entropy-gated and attention-guided token pruning, from model evaluation to accelerator implementation on AMD ZCU104.

View repository

Vitis HLS · XRT · C++

End-to-End ViT Inference on Alveo U250

Inference kernels and host–device integration, with loop pipelining, unrolling, memory partitioning, and latency analysis.

Reinforcement Learning · Computer Architecture

SmartBypass

Online reinforcement learning for adaptive STT-RAM last-level cache bypassing, using reuse and system feedback to manage writes.

Diffusion Transformers · Feature Caching · FPGA

CRAFT: Diffusion Transformer Acceleration

Adaptive feature reuse across denoising timesteps, paired with a configurable accelerator for efficient DiT inference.
