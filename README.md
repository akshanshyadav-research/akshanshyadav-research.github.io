# Akshansh Yadav — Academic Portfolio

Personal academic website of Akshansh Yadav, Ph.D. researcher at IIT Jodhpur.

The root files are the deployable static website. The `source/` directory and `portfolio-source.zip` contain the complete editable Next.js and Tailwind CSS project.

GitHub Pages should serve the `main` branch and `/(root)` folder. To edit, change files in `source/`, run `npm ci` and `npm run build` there, and publish the contents of `source/out/` to the repository root. Keep `.nojekyll` in the root. Do not upload `node_modules` or `.next`.

Photographs and publication material remain their respective owners' content.
